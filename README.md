# 🐍 Snake Fruit 2D - (Projeto do curso SENAI) 

Um jogo clássico da **Cobrinha (Snake)** desenvolvido utilizando apenas **HTML5, CSS3 e JavaScript puro**, executado diretamente no navegador.

O projeto recria a experiência retrô do Snake com uma interface moderna, frutas, pontuação, níveis de dificuldade e mecânicas aprimoradas.

---

## 🎮 Sobre o Projeto

**Snake Fruit 2D** é um jogo web desenvolvido com foco em:

* Prática de lógica de programação.
* Manipulação do elemento HTML5 Canvas.
* Desenvolvimento de jogos 2D no navegador.
* Organização de código front-end sem dependências externas.

O jogador controla uma cobra que deve coletar frutas para aumentar sua pontuação, evitando colisões com obstáculos e com o próprio corpo.

---

## ✨ Funcionalidades

- ✅ Movimento da cobra em tempo real.
- ✅ Controle por teclado (Setas e WASD).
- ✅ Sistema de pontuação.
- ✅ Recorde salvo automaticamente no navegador (`localStorage`).
- ✅ Frutas aleatórias com diferentes representações visuais.
- ✅ Crescimento da cobra ao coletar frutas.
- ✅ Aumento progressivo da velocidade.
- ✅ Sistema de Game Over.
- ✅ Botão de reinício.
- ✅ Interface responsiva.
- ✅ Renderização utilizando Canvas API.

## 🕹️ Como Jogar

### Controles

| Tecla                | Ação                |
| -------------------- | ------------------- |
| ⬆️ W / Seta cima     | Mover para cima     |
| ⬇️ S / Seta baixo    | Mover para baixo    |
| ⬅️ A / Seta esquerda | Mover para esquerda |
| ➡️ D / Seta direita  | Mover para direita  |

### Objetivo

🍎 Capture as frutas para ganhar pontos.

⚠️ Evite:

* Colidir contra as paredes.
* Encostar no próprio corpo.

Quanto mais frutas coletar, maior será sua pontuação e velocidade.

## 🚀 Como Executar

Não é necessário instalar nada.

### Opção 1 — Abrir diretamente

1. Baixe ou clone o projeto.
2. Abra o arquivo:

```
index.html
```

3. O jogo será iniciado no navegador.

---

### Opção 2 — Utilizando Git

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/snake-fruit-2d.git
```

Entre na pasta:

```bash
cd snake-fruit-2d
```

Abra o arquivo:

```bash
index.html
```
